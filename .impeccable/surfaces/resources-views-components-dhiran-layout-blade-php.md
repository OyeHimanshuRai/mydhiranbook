# Dhiran shop app shell (Operate)

Scope: the whole shop app, auth, public site and admin skin. Visitor mode: Operate (Persuade on public pages).

## Direction contract

THESIS: Dhiran is the bahi-khata made software: one committed oxblood-cloth shell holding calm white pages where every money table keeps the ledger's rhythm (a red margin line, a double rule at totals, right-aligned running figures). It refuses the neutral grey SaaS dashboard with a yellow accent.

OWN-WORLD: Palette (Committed, the cloth carries ~30-40% of the surface): cloth oxblood #7a1a1d (rail, top bar, auth brand panel), deeper cloth #5a1215 (pressed/active/dark parts); page ground cool white #fbfbfc (not cream/parchment), panel white #ffffff, graphite ink #1d2230, blue-black ink #1a2a4a for figures/links/primary buttons, margin-line red #c9484d at hairline weight, rule grey #d9dce3; status green #1f6f4a, crimson error #b3261e (icon + word keep it apart from the cloth), warning deep brass #8a5a00 only as text/outline/icon, never a yellow fill; focus ring = blue-black ink 2px with 2px white offset. No gradients, glass or glow. Type: system UI stack with Devanagari fallbacks, no web-font request; tabular-nums for figures; 12px +0.06em uppercase labels for table headers/field groups; serif wordmark "dhiran.". Components: 6px radius, 1px hairlines, 44px touch buttons (40px desktop), ink-filled primary, outlined secondary, crimson-outlined destructive; badges = word + tone; tables with a double rule under the header, a 1px inset red margin line at the left of money tables/cards, totals row with a double rule above, figures right-aligned tabular; 1px dotted stitch divider in the shell; flat cards, shadows only on toast/dialog.

STORY: A shopkeeper recognises their own book at a glance, trusts the figures because the ledger rhythm is intact, and always finds the next action as the ink button.
